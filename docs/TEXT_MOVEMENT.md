# Text movement v1.1

Tekst kan flyttes på to nivåer:

## 1. Flytte hele elementet
Dra tekst-elementet, kortet, boksen eller knappen rundt på canvas.

## 2. Flytte teksten inni elementet
I høyre panel under **Tekst / skrift**:
- Tekst X
- Tekst Y
- Horisontal justering
- Vertikal justering
- Hurtigknapper: venstre, høyre, opp, ned, reset

Disse verdiene eksporteres i prosjektets JSON:
- `textX`
- `textY`
- `textAlign`
- `textVAlign`
