# Collectium Startside V4

Innhold:

- `app/page.tsx` erstatter startsiden med en liten server-wrapper.
- `components/StartsideV4Client.tsx` er interaktiv klientkomponent.
- `public/images/collectium-family.png` er familiebildet.
- `public/images/collectium-c-logo.png` er Collectium C-logoen.

Funksjoner:

- Samler / Historie / Finans-knapper endrer objektinformasjonen i høyre felt.
- Sedler / Mynter-knapper endrer objektpresentasjonen.
- Funksjonslisten endrer innhold i høyre panel.
- Månedlig / Årlig endrer prisvisning.
- Norsk tekst bruker norske tegn.
- Ingen fiktive markedsdata er lagt inn.

GitHub-verktøyet stoppet direkte commit av denne store klientkomponenten, derfor ligger filene som klar pakke.
