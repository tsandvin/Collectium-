# Skins

Skins styrer visuelt uttrykk: farger, bakgrunn, rammer, spacing, tone og skin-spesifikke tokens.

Skins skal ikke eie ruter, datahenting, sidebar, topbar eller databasekobling.

Aktive skins ligger i `collectium-skins.ts` og matcher `lib/theme.ts`. Selve visuelle tokens ligger i `app/globals.css` under `html[data-template="..."]`.
